# TIDELINE · 潮线 — 单人潮汐撤离

> 第一人称（3D）单人 PvE 战术撤离原型 · 依据 01–07 号设计文档实现
> 核心机制：**潮汐是主角**——水位随回合涨落，淹没低地、浮起集装箱、把撤离点变成孤岛，逼你在涨潮前带着战利品撤离。
> **产品定位（2026-08-29 裁定）**：门面只许有一张脸——**SALVAGE 单人潮汐撤离**。BREACH / SURGE 已裁定为作废旧案，从入口移除并归档，玩家看不到。

---

## 你在这游戏里是谁 / 你在玩什么

你是**潮民（Tide-dweller）**：背一身债、踩着随时被淹的滩涂讨生活。**主页就是你的旱坞（drydock）**——
上工前在这里看账、选装备、听潮讯，然后下一次海。

主页永远挂着三个数字，逼你记住目标：

| 数字 | 含义 | 怎么变 |
|---|---|---|
| **债务** | 你还欠世界的信用点 | `max(0, 12000 − 累计打捞收益)` |
| **信用点** | 上岸后的净结余 | `max(0, 累计打捞收益 − 12000)` |
| **撤离次数** | 你活着带回东西的次数 | 每次成功撤离 +1（也是解锁干员 / 枪械的进度） |

> 一句话目标：**还清 12000 债务，成功上岸。**

### 5 秒法则（陌生人验收标准）
任何人停在标题屏 5 秒，必须能答出这三问：
1. **这是什么游戏？** → 单人潮汐撤离：涨潮前潜入、搜刮、撤离。
2. **一局多长？** → 硬上限 720s，满潮 3.2m 会把低地淹没、关闭撤离点，逼你抢时间。
3. **死了会怎样？** → 没撤出来就一无所有（这局收益清零），但债务不清、下次再来。

## 怎么玩（最快路径）

**双击打开 `web/index.html` 即可玩**（单 HTML 文件；3D 需联网加载引擎，离线自动走 2D）。

1. **标题屏（旱坞）**：看债务 / 信用点 / 撤离次数，点「开始打捞」或「怎么玩」。
2. **部署屏**：
   - 选**干员**（初始解锁 1 名，其余 7 名按累计撤离次数逐步解锁——锁定卡是钩子，不是缺陷）；
   - 选**枪械**（初始 1 把，其余按撤离次数解锁）；
   - 看**潮讯条**（当前水位 / 满潮高度 / 撤离点开放情况），决定这局的赌注与节奏；
   - 点「下海」开局。
3. **第一人称对局**：
   - 点击画面 **锁定鼠标** 控制视角（移动鼠标 = 转向/俯仰）
   - `W A S D` 移动（相对视角前后/左右）
   - **左键** 开火 · `R` 换弹 · `Q` 技能槽（预留）· `E` 长按拾取战利品
   - 水越深越慢；水深 > 2.0m 自动降级为**副武器（手枪）**，不是缴械
   - 集装箱随水位浮起，水涨后变成通往高地 / 撤离点的新路
   - 在**撤离点开放期间**抵达并撤离即结算收益；硬上限 720s 到 / 阵亡则本局清算
4. **结算屏**：显示撤离成功与否、本局价值、所处潮汐相位、击杀、承伤、残血，以及**本局新解锁的干员 / 枪械**。

> 若浏览器不支持 WebGL，或 Three.js CDN 加载失败（如离线），游戏会**自动回退到俯视 2D 模式**，机制完全一致。

## 上线部署（静态托管，访客点链接即玩）

`web/` 目录即站点根，可零配置部署到任意静态托管：

- **CloudStudio 零配置**：把 `web/` 作为静态站点目录部署即可获得分享链接（访客点开即玩，无需本机步骤）。
- **GitHub Pages（备选）**：
  1. 推送本仓库到 GitHub；
  2. 仓库 **Settings → Pages → Source** 选 **Deploy from a branch** → 分支 `main` + 目录 `/ (root)` → Save；
  3. 访问 `https://<用户名>.github.io/<仓库名>/web/`。

### 关于 Three.js CDN 依赖
`web/index.html` 通过 `https://cdnjs.cloudflare.com/.../three.min.js (r128)` 加载 3D 引擎。
- 联网时一切正常（托管访客默认可用）。
- **离线 / 自包含方案**：下载 `three.min.js`（r128）放到 `web/vendor/three.min.js`，
  并把 `index.html` 中 `<script src="...cdnjs...">` 改为 `<script src="vendor/three.min.js">`。
  （`.gitignore` 已放行 `web/vendor/`。本仓库因沙箱无外网，未预置该文件。）

### 推送到 GitHub（如需，此步骤需你提供仓库地址）
当前已 `git init` 并在本地提交。推送到 GitHub 需你：
- 在 github.com **新建空仓库**（不要勾选自动生成 README / LICENSE，避免冲突）；
- 然后告诉我仓库地址，我执行：
  ```bash
  git remote add origin <你的仓库URL>
  git branch -M main
  git push -u origin main
  ```
  或你在本地自行执行这三条命令。
