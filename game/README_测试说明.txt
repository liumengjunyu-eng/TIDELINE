【TIDELINE 潮线】P0 冒烟测试说明

感谢参与测试！你不需要任何操作说明，双击运行即可。

一、启动方式
- Windows：双击 TIDELINE.exe
- Web：打开 index.html（推荐 Chrome/Edge）
启动后控制台（CMD窗口）会显示三行：
  [SMOKE] 进入主场景，地形/网格/相机已构建
  [SMOKE] 当前潮汐相位: LOW
  [SMOKE] 潮汐启用: true
若无报错，即正常启动。

二、对照实验（可选）
以下启动参数用于A/B对照，普通测试者无需设置：
- 无参数：潮汐正常（实验组）
- --tide-off：潮汐关闭（对照组，水位锁低潮）
- --practice=1：练习局模式（数据不落盘）
Web版对应URL参数：?tide=0 或 ?practice=1

三、你需要做的
玩一局（约 2 分钟），然后按以下四行格式反馈：

【潮汐节奏】一局共 100 秒，水位会自己涨上来，请全程留意：
-  0–40 秒  低潮：水位 0 → 0.15m，几乎没感觉，地面干爽
- 40–75 秒  涨潮：水位 0.15 → 1.50m，干船坞变运河，走路开始变慢
- 75–100 秒 满潮：水位 1.50 → 3.20m，B 点成孤岛，撤离点浮到浮桥上，必须踩桥撤离
如果你玩了 2 分钟还没看到水明显涨上来，请在第 4 行说明。
1. 能否启动（无控制台报错）:
2. 控制台报错（如有）:
3. 是否按预期跑通（玩家落地/拾荒者抢高地/满潮撤离点浮起）:
4. 手感/观察是否不对:

四、数据自动回收
游戏结束后，数据已自动保存。Windows版请将 user://telemetry_*.jsonl 文件发回；Web版浏览器控制台执行 Telemetry.export_to_web_storage() 导出。

再次感谢！
